# Pedantically Reinforced Large Language Model (PRLLM)

## Description

This novel work present a Pedantically Reinforced Large Language Model (PRLLM), which serves a didatic purpose so the reader can familiarize with the concepts of Reinforcement Learning from Human Feedback (RLHF) and Principal Policy Optimization (PPO) algorithms commonly used for LLM preference alingment in the post-training phase of this huge models. 

The name of the model points out the goal: to take a language model and favour its precision, elonquency and usage of high level vocabulary and elaborate expressions and constructs, making it more pedantic, like an erudite English scholar from the late 19th century.
