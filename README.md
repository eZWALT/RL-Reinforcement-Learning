# RL-Reinforcement-Learning
UniPD - DS Reinforcement Learning Subject 2025-2026 Q1. This subject explores the machine learning subset of algorithms related to reinforcement learning through a comprehensive review of Sutton &amp; Barto.

## Contents

The directory is structured in the following way:

- **THEORY**: Contains slides and theoretical resources
- **EXAMS**: Past years partial and final exams
- **SUMMARIES**: Collection of curated summaries of RL principles and theory
- **LAB**: Laboratory sessions on Q-Learning, MonteCarlo, TD, Sarsa...
- **PROJECT**: Final personal project on RLHF: Pedantically Reinforced Large Language Model (PRLLM)
